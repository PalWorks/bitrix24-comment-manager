One command brings up the backend and its database on any machine with Docker, from a laptop to a five dollar VPS. 

git clone https://github.com/PalWorks/bitrix24-comment-manager
cd bitrix24-comment-manager
cp .env.docker.example .env
docker compose up -d

Fill in your Bitrix24 client ID and secret in .env first. The compose file generates the signing and encryption keys for you on first run. Put it behind a domain with HTTPS, then paste that origin below.
