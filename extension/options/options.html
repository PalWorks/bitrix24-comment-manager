Backend

Every comment is routed through a backend so the audit trail lives somewhere the agent cannot edit. Choose how you want to get one.

We run the backend, you paste the URL we send you. Nothing to deploy, nothing to patch, and no server of your own to keep alive.

Not open yet. The plans, what each one includes, and how to be told when it opens are all on the page.

You run the backend, so the audit log and the Bitrix24 credentials never leave your infrastructure.

Already have one? Paste the origin your administrator gave you into the field below and you are done.

Setting it up yourself? Register a Bitrix24 application first, following the setup guide, then bring the backend and its database up with one command: 

git clone https://github.com/PalWorks/bitrix24-comment-manager
cd bitrix24-comment-manager
cp .env.docker.example .env
docker compose up -d

Fill in your Bitrix24 client ID and secret in .env first. Put it behind a domain with HTTPS, then paste that origin below.
